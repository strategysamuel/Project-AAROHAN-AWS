# Engineering & Integration Documentation (docs/)

This directory houses technical documentation, API specifications, onboarding manuals, and runbooks.

## Document Directory

1. **api-specs/**: Technical API descriptions and schema files.
2. **architecture/**: System architecture records and design summaries.
3. **onboarding-guides/**: Developer setup instructions and environment access guidelines.
4. **runbooks/**: Operational runbooks, monitoring logs setup, and support guides.

## Guidelines
* All files must be written in Markdown format.
* Maintain file links and cross-references when updating documentation.
