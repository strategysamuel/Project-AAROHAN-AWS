# Release Notes v1.0

## Release Scope

This release packages the current AAROHAN portal, backend services, and judge-facing documentation as the v1.0 hackathon submission.

## Included

- Login and role-aware portal experience.
- Demo Studio and guided lending workflow.
- Customer Onboarding, CKYC, GST, AA, EPFO, MCA, FHC, Credit Decision, CAM, Executive Dashboard, Reports, and AI Banking Copilot.
- AWS Amplify frontend deployment.
- ECS and ALB deployment artifacts in the repository.

## Validation

- Production build completed successfully.
- Regression suite passed.
- Live portal access confirmed.
- Authenticated browser flow confirmed.

## Known Issues

- Full live AWS console evidence for ECS/ALB/CloudWatch was not directly captured from this workspace.
